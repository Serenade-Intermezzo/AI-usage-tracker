Codex 用量统计 0.3.0

这是本地绘制的原生窗口，保留圆角、大字体和日用量 / 热力图 / 模型图表。
只统计本机可确认的、指定 OpenAI 账号在 Codex GUI / CLI 中的用量，不启用 Claude Code。

窗口与图表
右上角三个按钮分别为最小化、最大化 / 还原、关闭。最大化填满可用桌面。
F11 进入 / 退出整屏全屏，Esc 退出并恢复之前的普通或最大化窗口。
双击顶部空白处可最大化 / 还原，小屏幕和高缩放下页面内容可滚动。
“图表分析”包含全体成员占比饼图，可切换本月、本周和累计。

跨网络接入（推荐 Tailscale）
1. 打开“成员与设备 → Tailscale 连接”，安装后登录并连接，完成系统与官方浏览器授权。
2. 其他成员也安装并连接，加入同一个获准网络，或接受你共享中心设备的邀请。
3. Tailscale 网络邀请与统计成员配置是两份东西，都需要完成。
4. 成员管理的“邀请接入”会自动填写中心 Tailscale 地址；可复制配置或整段操作说明。
5. 对方在“加入汇总中心”粘贴配置，先测试中心连接，再保存并重启后台。
不同网络不能直接使用 10.x / 192.168.x 等局域网地址。

多人使用
1. 在一台经常开机的电脑上，打开“设置与连接”，选择“作为汇总中心”。
2. 填写本机使用者和设备名称；需要其他电脑连接时勾选允许连接，保存并等待自动重启。
3. 进入“成员与设备 → 管理成员”，为每位使用者添加成员。
4. 输入其他设备能访问的中心地址，为选中的成员生成并复制接入配置。
5. 其他电脑安装本程序，在 Codex 中登录同一 OpenAI 账号；进入“设置与连接 → 加入汇总中心”，粘贴自己的接入配置。
6. 同一人的多台电脑使用同一份配置，每台电脑自动保留独立设备编号。
7. 主窗口顶部选择“本机 / 全体成员 / 某位成员”，查看周月报和对应图表。

月度起始日
只能在汇总中心本机修改。支持每月 1–31 日，短月份取最后一天。
所有成员自动同步同一设置；修改后重新计算历史月报，周报不变。
周报为北京时间周一至周日，所有报表统一使用北京时间。
后台每分钟保存快照，跨周跨月自动归档；关机重开补算，离线补传更新历史。

成员与设备
成员管理支持搜索、改名、查看设备和复制邀请，只能删除未关联设备的空成员。
可查看每个人的本周、本月和累计用量、设备数，以及设备在线 / 离线、待上传数量和最近联系。
同一事件重复上传不会重复计数。离线设备会保留待上传记录，恢复连接后自动补传。
设备首次关联成员后保持固定，修改姓名不会拆分历史；不要跨电脑复制整个数据目录。
出现离线、待上传或扫描未完成提示时，当前数值仅代表已经收到的用量。

数据与隐私
接入配置包含私有团队密钥，只私下交给成员。公网请使用 HTTPS 或可信 VPN。
只上传计量事件，不上传聊天正文、标题、项目路径或账号登录文件。
历史只有在账号归属可确认时才纳入；后台停止期间的无账号标记历史不推定归属。
本工具不能辨认一个共用系统中谁实际操作了电脑；人员归属由成员和设备登记确定。

Windows 10 / 11 x64
安装 Python 3.10+ 与 Node.js 22.5+，解压到固定目录，首次双击 scripts\install-native-windows.cmd。
以后使用桌面 Codex Usage Tracker 快捷方式。
数据保存在 %LOCALAPPDATA%\CodexUsageTracker\data-current-account。
关闭窗口不停止后台；要关闭登录后启动，在 shell:startup 中删除 Codex Usage Background。

Ubuntu / 其他 Linux
按照根目录 README.md 安装依赖和 systemd 用户服务，运行 scripts/open-local-gui.sh。
已有本机源码：$HOME/.local/share/ai-usage-tracker
已有数据：$HOME/.local/share/ai-usage-tracker/data-current-account
停止后台：systemctl --user stop ai-usage-tracker
查看后台：systemctl --user status ai-usage-tracker

完整安装、设置、统计范围、备份方式和验证边界请查看根目录 README.md。
